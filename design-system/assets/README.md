# useclis assets

[icon.svg](icon.svg) is the code-bracket mark shared with the app's `public/favicon.svg`. Set the wordmark as lowercase `useclis` in Inconsolata, followed by a green dot; see the [wordmark specimen](../guidelines/brand-wordmark.card.html).

Repository-owner avatars under `public/logos/` identify listed projects. They are third-party materials, separate from the useclis identity. Font and icon license notices live in `public/licenses/`; see [third-party materials](../../THIRD_PARTY.md).
